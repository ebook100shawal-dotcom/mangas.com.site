# MangaVerse Marketplace — starter website

A responsive static storefront concept for an original manga catalog and creator submission flow.

## Included
- 250 catalog entries with original generated titles and short concept synopses.
- First 5 entries marked free.
- Bundle pricing UI: 100 paid titles for $3 and all 245 paid titles for $5.
- Search, genre filters, free/paid filter, sorting, book-detail modal, and mobile layout.
- Creator submission form demo.

## Important limitations before public launch
This is a front-end website prototype, not a fully operating publishing business:
- The catalog entries are story concepts/metadata, not 250 complete illustrated manga ebooks. The cover art is generated with CSS shapes and symbols.
- Checkout buttons are demo interactions. No money is charged and no ebook downloads are delivered.
- The creator submission form only stores demo submissions in the visitor's browser session; it does not upload files or send them to an owner.
- Before launch, add completed licensed/original comic files, secure server-side accounts and access control, a database, file upload/storage, moderation and copyright process, and a payment provider available for your country.
- Do not advertise full books until the completed files exist. Clearly state the terms for the 100-title bundle (which 100 titles are included) and the all-245 bundle.

## Run locally
Open `index.html` in a modern browser. For hosting, upload the files in this folder to GitHub and enable GitHub Pages, or use another static host. A backend is required for real payments, secure downloads, and publishing submissions.
